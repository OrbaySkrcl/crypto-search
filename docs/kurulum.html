Bölüm 1

Önce anahtarları topla

Kuruluma başlamadan bunları hazırla. Hepsini bir not defterine yapıştır — birazdan tek tek gireceksin. Topladıkça aşağıdaki kutuları işaretle, sayfa hatırlar.

1.1 · Telegram botu

Alarmların telefonuna düşmesi için. Bu olmadan sistem sana hiçbir şey söylemez.

BotFather'ı bul

Telegram'da arama kutusuna @BotFather yaz, mavi tikli olanı aç.

Yeni bot oluştur

/newbot yaz ve gönder. Bir isim ver (örn. Alpha Hunter), sonra bir kullanıcı adı ver — mutlaka bot ile bitmeli (örn. benim_alpha_hunter_bot).

Token'ı kopyala

BotFather sana şuna benzer bir şey verecek. Bu senin TELEGRAM_BOT_TOKEN'ın:

token
8123456789:AAHk3xY_pQrStUvWxYz1234567890abcdefg
Kimseyle paylaşma

Bu token şifre gibidir. Eline geçen kişi senin botunu kontrol eder.

Kendi chat id'ni bul

Yeni botunu kullanıcı adıyla ara, aç, Start'a bas ve bir mesaj yaz — "merhaba" yeter. Sonra tarayıcıda şu adresi aç (<TOKEN> yerine yukarıdakini yapıştır):

tarayıcıda aç 
https://api.telegram.org/bot<TOKEN>/getUpdates

Karışık bir metin çıkacak. İçinde şunu ara — id yanındaki sayı senin TELEGRAM_CHAT_ID'in:

çıktı
"chat":{"id":123456789,"first_name":...
Boş çıktı görüyorsan

{"ok":true,"result":[]} görüyorsan bota mesaj atmayı unutmuşsundur. Mesaj at, sayfayı yenile.

1.2 · Apify

Twitter'dan veri çekmek için. Ücretsiz alternatifi (Nitter) var ama sürekli düşüyor — sistemin gerçekten çalışması için buna ihtiyacın olacak.

Kaydol

apify.com → Sign up (Google ile giriş yapabilirsin).

Token'ı al

Sol menüden Settings → API & Integrations → Personal API token kutusundaki uzun metni kopyala (apify_api_ ile başlar). Bu senin APIFY_TOKEN'ın.

Bütçe

Ücretsiz katman ayda 5 $ kredi veriyor; bot 10 dakikada bir çalıştığında bu genelde yetmez. Ayda ~5–15 $ ayırmayı bekle. Bütçen yoksa TWEET_SOURCES=nitter bırak — sistem yine çalışır ama veri düzensiz gelir.

1.3 · Birdeye

Fiyat geçmişini hassas almak için. Olmazsa sistem GeckoTerminal'i kullanır: ücretsiz ama yavaş. bds.birdeye.so → kaydol → API Keys → yeni anahtar → kopyala. Bu BIRDEYE_API_KEY.

1.4 · Helius

Scam token tespiti için (mint yetkisi, cüzdan yoğunluğu). Olmazsa herkese açık Solana RPC'si kullanılır — yavaş ama çalışır. dashboard.helius.dev → kaydol → ana ekrandaki API Key'i kopyala. Bu HELIUS_API_KEY.

1.5 · Pano şifresi

Kendin uydur. Örneğin Kahve!2026_Panom. Bu WEB_PASSWORD.

Boş bırakma

Şifresiz bırakırsan bulduğun alfa hesapları internette herkese açık olur — yani bütün emeğin başkasının eline geçer.

Bölüm 2

Railway'e kur

Buradan sonrası tamamen tarayıcıdan. Yaklaşık 15 dakika.

Projeyi oluştur

railway.app → Login with GitHub → New Project → Deploy from GitHub repo. Erişim izni ver, sonra OrbaySkrcl/crypto-search deposunu seç.

İlk kurulum hata verirse normal

Veritabanı ve ayarlar henüz yok. Sıradaki iki adım bunu düzeltecek.

Veritabanı ekle

Aynı proje ekranında + Create (veya + New) → Database → Add PostgreSQL.

Bitti. Railway bağlantıyı kendisi kurar, sen bir şey yapmayacaksın.

Ayarları gir

Soldaki crypto-search servisine tıkla (veritabanına değil) → Variables → Raw Editor. Aşağıdakini yapıştır ve BURAYA yazan yerleri kendi değerlerinle doldur.

Railway → Variables → Raw Editor 
CHAINS=solana
TWEET_SOURCES=apify,nitter
APIFY_TOKEN=apify_api_BURAYA_SENIN_TOKENIN
BIRDEYE_API_KEY=BURAYA_SENIN_ANAHTARIN
HELIUS_API_KEY=BURAYA_SENIN_ANAHTARIN

TELEGRAM_BOT_TOKEN=BURAYA_SENIN_TOKENIN
TELEGRAM_CHAT_ID=BURAYA_SENIN_CHAT_IDIN
ALERTS_ENABLED=true
ALERT_MIN_ALPHA_SCORE=65

WEB_ENABLED=true
WEB_USER=admin
WEB_PASSWORD=BURAYA_KENDI_SIFREN

SEARCH_QUERIES=pump.fun/coin | dexscreener.com/solana | "CA:" solana | "contract:" solana

INGEST_INTERVAL_MINUTES=10
ENRICH_INTERVAL_MINUTES=5
SCORE_INTERVAL_MINUTES=60
LOG_LEVEL=INFO

Deploy / Save de. Railway yeniden kuracak.

Anahtarın yoksa satırı sil

Örneğin Birdeye almadıysan BIRDEYE_API_KEY satırını tamamen sil — boş bırakma.

Panoya adres ver

Aynı serviste Settings → aşağı in → Networking → Generate Domain. Sana şuna benzer bir adres verecek:

panonun adresi
crypto-search-production-a1b2.up.railway.app

Tarayıcıda aç. Kullanıcı adı admin, şifre senin WEB_PASSWORD'ün. Panoyu görüyorsan kurulum bitti.

Çalıştığını doğrula

Deployments → en üstteki dağıtıma tıkla → Logs. Şu satırı ara:

loglar
INFO Alpha Hunter calisiyor | zincir=solana kaynak=apify,nitter
     | ingest 10dk, enrich 5dk, score 60dk

Bu satır varsa bot ayakta ve tweet toplamaya başladı.

Bölüm 3

Ne bekleyeceksin

Bu en önemli bölüm. Sistem ilk gün sana bir şey söylemez — ve bu bir hata değil, tasarımın kendisi.

İlk 10 dakika
Bot tweet toplamaya başlar. Panoda "çağrı" sayısı artar.
İlk 1–2 saat
İlk kontratlar doğrulanır, fiyatları çekilir. "Son çağrılar" dolar.
İlk 24 saat
Çağrılar izleniyor durumunda. Henüz kimse puanlanmadı.
2–3 gün
İlk skorlar çıkar. Çoğu hesap UNRATED veya F olur — bu doğru davranış.
1–2 hafta
Tablo anlamlanır. B ve C tier hesaplar belirir.
1 ay ve sonrası
A/S tier hesaplar ortaya çıkar. Telegram alarmları gelmeye başlar.

Neden bu kadar sürüyor?

Çünkü sistem bir hesabı puanlamadan önce onun çağrılarının ne olduğunu görmek zorunda. Bir çağrı 7 gün izlenir. Bir hesabın puan alması için en az 4 tamamlanmış çağrısı olmalı. Yani matematiksel olarak minimum 7 gün, pratikte 2–4 hafta.

Bunu bir kusur sanma

Hemen sonuç veren bir sistem, sonucu uydurdu demektir. Beklemenin kendisi algoritmanın çalıştığının kanıtı.

Hemen bir şey görmek istersen

Bildiğin bir hesabı geçmişe dönük taratabilirsin. Bunun için Yol B'yi (kendi bilgisayarın) sadece bu iş için kullan:

terminal 
python -m alpha_hunter backfill hesapadi --days 60
python -m alpha_hunter inspect hesapadi

Bu, o hesabın 60 günlük tüm çağrılarını, giriş fiyatlarını ve sonuçlarını döker. Birkaç dakika sürebilir.

Ek

Kendi bilgisayarına kurmak

Sadece denemek veya backfill çalıştırmak istiyorsan. Gerçek kullanım için Railway'i öneriyorum — bilgisayar kapanınca bot durur ve veri toplamaz.

Windows

Önce python.org/downloads → Python 3.11+ indir. Kurulumda "Add Python to PATH" kutusunu mutlaka işaretle. Sonra Git'i kur (hep İleri). Başlat menüsüne cmd yaz, Komut İstemi'ni aç ve yapıştır:

komut istemi 
cd %USERPROFILE%\Desktop
git clone https://github.com/OrbaySkrcl/crypto-search.git
cd crypto-search
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt

Mac

Terminal'i aç (Spotlight → Terminal) ve yapıştır:

terminal 
cd ~/Desktop
git clone https://github.com/OrbaySkrcl/crypto-search.git
cd crypto-search
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
git bulunamadı derse

xcode-select --install yaz, kurulumu bekle, sonra tekrar dene.

Ayarları gir ve çalıştır

crypto-search klasöründeki .env.example dosyasını kopyala, kopyanın adını .env yap. Not defteriyle aç, Bölüm 1'de topladığın anahtarları karşılıklarına yapıştır, kaydet. Sonra:

terminal 
python -m alpha_hunter initdb   # veritabanını kur (bir kez)
python -m alpha_hunter doctor   # her şey bağlanıyor mu?
python -m alpha_hunter run      # bot + pano

Tarayıcıda http://localhost:8000 adresini aç. Durdurmak için terminalde Ctrl+C.

Bu sistem korelasyon bulur, insider olduğunu kanıtlamaz.

Yüksek skorlu bir hesap içeriden bilgi alıyor olabilir, güçlü bir network'ü olabilir, ya da sadece çok iyi olabilir. Sistemin söylediği tek şey şu: "Bu hesabın geçmiş çağrıları rastgele şansla açıklanamıyor." Daha fazlası değil. Bir hesabın S tier olması, bir sonraki çağrısının tutacağı anlamına gelmez. Bu bir araştırma aracıdır, yatırım tavsiyesi değildir.
